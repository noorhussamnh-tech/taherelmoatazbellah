# Taher El Moataz Bellah

Personal website of Taher El Moataz Bellah: screenwriter of El Da7ee7 episodes and author of seven books.

A static site with no build step: `index.html` plus the photos and book covers in `images/`.

## Deploying on Vercel

Import this repository in Vercel and deploy with the defaults. Framework preset: **Other**. No build command, and the output directory is the repository root.

## Editing

- Text and layout are in `index.html`.
- To swap a photo or cover, replace the file in `images/` and keep the same name.
- Fonts load from Google Fonts. The heading/body fonts are set in the `TRIAL: Heartbeat deck fonts` block near the end of the `<style>`; delete that block to return to the previous fonts.
